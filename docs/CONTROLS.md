# Controls Reference

One unified set of input actions serves keyboard, gamepad, and on-screen touch controls.

## Actions & Mappings

| Action Name | Keyboard Primary | Keyboard Alt | Gamepad (Standard / Xbox layout) | Touch UI |
|---|---|---|---|---|
| `move_left` | `A` | `Left Arrow` | D-Pad Left / Left Stick Left | Left D-Pad Button |
| `move_right` | `D` | `Right Arrow` | D-Pad Right / Left Stick Right | Right D-Pad Button |
| `jump` | `Space` | `W` / `Up Arrow` | Button A (Cross) | Jump Button (Up/A) |
| `attack` | `J` | - | Button X (Square) | Attack Button (J/X) |
| `magic` | `K` | - | Button Y (Triangle) | Magic Button (K/Y) |
| `dodge` | `L` | `Shift` | Button B (Circle) / Right Trigger | Dodge Button (L/B) |
| `block` | `I` | `S` / `Down Arrow` | Left Shoulder / L1 | Block Button (I/L1) |
| `heal` | `H` | - | Button D-Pad Up | Heal Button (H) |
| `pause` | `Escape` | `P` | Start / Options | Pause Button |
| `debug_hitbox` | `F1` | `H` (with Alt) | - | - |
